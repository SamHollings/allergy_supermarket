# allergy_supermarket
Making it easier to find products at the super market which contain allergens.

## Aim
- Produce a site where people can see for popular italian supermarkets the products organised by allergens.
- Specifically, you should be able to search and filter by allergens and return products which do not contain, for example nuts.
- Ideally, a picture of the product and its packaging, alongside its name, details, allergen information, ingredients, etc.

## Plan
- populate database with the product information for the chosen supermarkets
- enable regular update of the data
- build frontend to dynamically display this information, filter, search etc.
- get this properly hosted
